# Basic Containerized App

This application is a very basic implementation of vite (front-end), exrpess (back-end), containerized in docker and run with docker compose.

## Requirements
- Docker
- A web browser

## Instructions

### 1. Clone this repo:
```bash
git clone git@github.com:entropicvail/docker-workshop.git
```
### 2. Navigate into the repo directory:
```bash
cd docker-workshop
```

### 3. Start the app:
```bash
docker compose up
```

### 4. To stpo the app (from the docker-workshop directory):
```bash
docker compose down
```
